# scripts/

Helper scripts for development, deployment, and ops. Most are bash for
the cross-platform happy path (Windows users use Git Bash); several are
PowerShell (`*.ps1`) for callers that need pure-pwsh — same contracts
where they overlap.

| Script | What it does | When to run |
|---|---|---|
| **`preflight.sh`** | 6-section sanity check: LLM keys / gateway up / vision smoke / config sync / Chrome stability / action-registry consistency. Exits non-zero on FAIL. | Before any benchmark or LLM-comparison session. |
| **`dev-relaunch.sh`** | Safe rebuild loop: kill running Sirin → free port → `cargo build --release` → relaunch. Falls through to alt port (#14 zombie defence). | Inner dev loop after a code change. |
| **`watch-sirin.ps1`** | Optional PowerShell watchdog. Polls every 5s; relaunches if binary is newer than the running process. | Long-lived dev sessions where you want auto-restart on rebuild. |
| **`install-sirin-daemon-task.ps1`** | Installs / removes / inspects the per-user Windows Task Scheduler entry. Defaults to direct `sirin.exe --headless`, no execution-time limit, one-minute restart retries, StartWhenAvailable and a five-minute safe wake-up guarded by IgnoreNew; `Plan` emits the exact definition without registration. | Internal implementation used by the unified installer for logged-in-session unattended mode; pass `-UseWatchdog` only for development. |
| **`install-codex-ios-integration.ps1`** | Installs the Sirin-owned iPhone Skill mirror and shared `sirin` Streamable HTTP MCP entry into the local Codex home; status compares managed file hashes. | After installing or upgrading Sirin's iPhone/Codex integration; restart Codex afterward. |
| **`install-codex-kb-integration.ps1`** | Installs or checks the Sirin-owned KB Skill mirror under the local Codex home, comparing hashes for every managed skill file. | After installing or upgrading Sirin's KB/Codex integration; use `Status` for a read-only drift check and restart Codex after `Install`. |
| **`install-sirin-ios.ps1`** | Single public Windows entry for Sirin physical-iPhone support. Initializes missing per-user defaults without overwriting edits, installs/upgrades the private Driver runtime, Sirin tasks and shared Codex integration, records binary-bound capture/control evidence, reports service/migration readiness, creates verifiable reboot evidence, and fail-closes legacy task retirement until capability, soak, and reboot gates pass. `-RunNow` waits for complete device readiness; a structurally sound install with an unavailable phone remains installed and reports `NEEDS_ATTENTION` instead of rolling back to the legacy control plane. | Use directly for portable installs; the Inno Setup package invokes the same entry as the original user and enforces its exit code. |
| **`verify-sirin-ios-source.ps1`** | Runs PowerShell parser checks, the complete mock-only Python Driver suite, focused Rust iPhone/MCP contracts, and `cargo check`, then writes a source-hashed JSON evidence report. `-FullRust` also runs the full Rust suite serially. It never contacts the phone or live Sirin/Driver endpoints and never changes services, firewall, DDI, or phone settings. | Before committing, packaging, or reviewing a Sirin iPhone candidate; CI uploads the same report. |
| **`install-ios-driver-runtime.ps1`** | Creates the private `%LOCALAPPDATA%\Sirin\ios-driver` Python runtime, obtains pinned go-ios from its hash-verified official npm package, and prepares a hash-verified unsigned Appium WDA IPA plus upstream license under `operator-assets`; never copies credentials/signing assets and never signs or installs WDA. | One-time install or upgrade of Sirin's internal Windows iPhone driver, independent of a SideTap checkout. |
| **`install-ios-driver-task.ps1`** | Installs / removes / inspects the private, on-demand acceptance-only `Sirin iOS Driver` task from Sirin-owned source without a logon trigger, execution-time limit, or one-shot crash behavior; `Plan` emits the exact definition without registration. | Internal implementation; Sirin daemon owns start decisions. |
| **`switch-sirin-daemon.ps1`** | Verifies an exact Sirin candidate on alternate loopback ports, requires the committed 190-tool inventory and fail-closed iPhone contract, then stages a reviewed SHA under an immutable `%LOCALAPPDATA%\Sirin\deployments\sirin-<sha12>` directory. Deploy switches only the scheduled-task action, verifies listener path/hash/UI, writes a manifest, and restores the prior action automatically on failure. | Before replacing the task-owned Windows daemon; run `Status` or `Verify` first and supply the reviewed SHA-256. `Verify` never deploys; `Deploy` requires a clean pushed Git HEAD and never uses repo build output as the live path. |
| **`verify-sirin-ios-physical.ps1`** | Starts temporary alternate-port Sirin/Driver candidates and writes source/binary-bound physical evidence. `Status` is passive; `Acceptance` requires an explicit phone-action switch and stable caller-provided `run_id`, then proves lease/link/process cleanup. | Final physical-device acceptance without replacing the current 7700/8770 services. |
| **`migrate-chatgpt-awake-guard.ps1`** | Reports the exact legacy `ChatGPTKeepAwake` startup/process state, then migrates it to Sirin only after the live internal guard is measured active; writes a rollback JSON and retains the old script. | Run `Status` after deploying Sirin power monitoring, `Migrate` only after reviewing live guard proof, or `Rollback` with the exact backup JSON. |
| **`switch-ios-driver.ps1`** | Backs up the three legacy/provider task definitions, switches `:8770` to Sirin's private Driver, and restores the old tasks automatically on failed health or read-only capture proof. | Use `Deploy` for the SideTap-to-Sirin provider cutover or `Rollback` with an exact backup directory. |
| **`soak-ios-device.ps1`** | Collects bounded JSONL stability evidence using only `tools/list` and `ios_device_status`; it never captures or controls the phone. Records minimum sample count and bounded inter-sample gaps so sleep or long pauses cannot masquerade as a continuous run; the public installer independently revalidates the raw JSONL. | Run before retiring the disabled SideTap rollback tasks; default duration is eight hours. |
| **`kill-port.sh`** / **`kill-port.ps1`** | Find and kill whoever owns the TCP LISTEN socket on `<port>`, regardless of process name. Silent if free; best-effort on permission errors. | Manually clearing a stuck port without restarting Sirin. Run by `dev-relaunch.sh` automatically on 7700-7703. |
| **`fetch-handoff.sh.example`** | Reference copy of `~/.claude/scripts/fetch-handoff.sh` — SessionStart hook that injects the latest mid-session handoff into a new Claude Code session. Includes hardened token handling (`umask 077` + 600 tempfile + `curl -K`). | One-time install: `cp scripts/fetch-handoff.sh.example ~/.claude/scripts/fetch-handoff.sh`. |
| **`check_kb_freshness.sh`** | Post-commit hook: scans files changed in the last commit and marks any KB entries whose `fileRefs` overlap as `STALE` via `kbMarkStale`. | Auto-installed by `install_kb_freshness_hook.sh`. |
| **`install_kb_freshness_hook.sh`** | Wires `check_kb_freshness.sh` into `.git/hooks/post-commit`. Idempotent; `--uninstall` to remove. | One-time setup per checkout. |
| **`squad-restart.sh`** | Kill → rebuild → relaunch → start N multi-agent squad workers. Default 2 workers on port 7710. | Bringing the dev squad back online after a code change to `multi_agent/`. |
| **`squad-status.sh`** | Pretty-print the multi-agent task queue (queued / running / done / failed counts + last 10 entries). | Monitoring squad progress without opening the web UI. |
| **`squad-cleanup-old-done.sh`** | Prune `done`/`failed` tasks older than N days from the queue (default 7, clamped 1–90). `SQUAD_CLEANUP_DRY_RUN=1` for preview. | Periodic maintenance — queue files grow unbounded otherwise. |
| **`verify-new-actions.sh`** | Smoke test for the MCP actions added 2026-04-17 (`page_state`, `ax_find` regex flags, `ax_snapshot`/`ax_diff`, `authz deny`). Runs against live AgoraMarket. | After landing changes that touch the action registry — quick "did I break the public surface" check. |
| **`ocr_windows_find_text.ps1`** | PowerShell helper that runs Windows OCR on a screenshot and returns the bounding boxes of `<Needle>`. Used by the `browser_exec action=ocr_find_text` MCP tool. | Don't invoke directly — Sirin spawns it. |

## Conventions

- **Exit codes**: 0 = success, non-zero = caller should see the error.
- **Idempotent**: re-running a script must not corrupt state. `dev-relaunch.sh`, `install_kb_freshness_hook.sh`, `squad-restart.sh` all conform.
- **Cross-platform paths**: scripts that read or write user data go through `$LOCALAPPDATA/Sirin/` on Windows or the equivalent (see `src/platform.rs::app_data_dir`). No hard-coded `~/IdeaProjects/Sirin` paths.
- **Quiet by default**: ops scripts suppress noise on the happy path. Use `-v` / set `DEBUG=1` for verbose output (when supported).

## Adding a new script

1. Drop the file into `scripts/`.
2. `chmod +x scripts/your-script.sh`.
3. Add a row above with what / when. The `scripts_index` test in `src/test_runner/parser.rs` walks the directory and panics if any file is undocumented.
