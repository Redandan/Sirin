Sirin · 使用說明

Sirin 是 AI 驅動的瀏覽器測試 daemon。本頁說明 如何讓任何 AI client(Claude / Cline / Cursor / 自寫 script)接它，以及對外暴露的 190 MCP tools。

⚡ 快速開始

Sirin daemon 跑在 http://127.0.0.1:7700，提供 3 個主要進入點：

路徑用途協議
/ui/儀表板 / 觀測 UIHTML
/mcp給 AI 用的 tool APIJSON-RPC 2.0 over HTTP
/wsUI 即時推送（snapshot 每 2s）WebSocket

確認 daemon 還活著：curl http://127.0.0.1:7700/api/snapshot， 應該收到 JSON。

🔌 接入方式

1. Claude Desktop / Claude Code

把這段加到 ~/.claude.json 的 mcpServers：

{
  "mcpServers": {
    "sirin": {
      "url": "http://127.0.0.1:7700/mcp"
    }
  }
}

重啟 Claude 後，新 chat 會看到 190 個 mcp__sirin__* tools。

2. Cline / Cursor / Roo Code（VS Code MCP）

{
  "mcp.servers": {
    "sirin": {
      "transport": "http",
      "url": "http://127.0.0.1:7700/mcp"
    }
  }
}

3. 純 curl / Python

# curl
curl -X POST http://127.0.0.1:7700/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "tools/call",
    "params": {
      "name": "run_test_async",
      "arguments": {"test_id": "agora_buyer_wallet"}
    },
    "id": 1
  }'

# Python
import requests
r = requests.post("http://127.0.0.1:7700/mcp", json={
    "jsonrpc": "2.0",
    "method": "tools/call",
    "params": {"name": "run_test_async",
               "arguments": {"test_id": "agora_buyer_wallet"}},
    "id": 1,
})
print(r.json())

4. sirin_call CLI（避 shell escaping 痛）

Sirin 自帶 target/release/sirin_call.exe，專門處理 CJK / Unicode payload： 

sirin_call --list                                       # 列所有 tools
sirin_call run_test_async test_id=agora_buyer_wallet    # key=value 語法
echo '{"test_id":"x"}' | sirin_call run_test_async      # stdin JSON

🛠️ 對外暴露的能力（190 tools）

類別主要 tools用途
🌐 瀏覽器自動化 browser_exec（45+ actions） navigate / click / type / screenshot / scroll / shadow_dump / vision
🧪 E2E 測試 run_test_async / run_test_batch / run_regression_suite 跑 YAML 描述的 user flow，自動 ReAct + 失敗截圖
📊 Coverage test_coverage / script_health feature 覆蓋率、replay 健康度（drift 警告）
📚 KB（知識庫） kb_search / kbWrite / kb_stats 跨 project 經驗共享（agora-trading KB）
👥 Multi-agent squad agent_assign_task / agent_queue_status PM/Engineer/Tester worker pool（worktree 隔離）
🔄 Handoff create_handoff / get_latest_handoff session 之間交接
🔍 Discovery run_test_pipeline / discover_features 自動爬 buyer/seller/admin 路徑
🧠 Memory memory_search / record_memory 跨 session FTS5 記憶
🔭 Phase B 觀測 live_trace / queue_status / tail_app_log 看 mid-run step / 排隊 ETA / 即時 log
🧹 Worktree GC cleanup_stale_worktrees 清舊的 multi-agent task worktree（#242）

完整清單：發 JSON-RPC tools/list 給 /mcp 即可拿到所有 tool 名稱 + schema。

📋 用法範例

跑一個 E2E test 並等結果

# 觸發
RUN=$(curl -sX POST :7700/mcp -d '{"jsonrpc":"2.0","method":"tools/call",
  "params":{"name":"run_test_async","arguments":{"test_id":"agora_buyer_wallet"}},"id":1}' \
  -H "Content-Type: application/json" | jq -r '.result.content[0].text' | jq -r '.run_id')

# 輪詢
curl -sX POST :7700/mcp -d '{"jsonrpc":"2.0","method":"tools/call",
  "params":{"name":"get_test_result","arguments":{"run_id":"'$RUN'"}},"id":1}' \
  -H "Content-Type: application/json"

截圖 + LLM 視覺分析

curl -X POST :7700/mcp -H "Content-Type: application/json" -d '{
  "jsonrpc":"2.0","id":1,"method":"tools/call",
  "params":{"name":"browser_exec","arguments":{
    "action":"screenshot_analyze",
    "prompt":"截圖：頁面是否正確顯示購物車，且 商品數量為 3 ?"
  }}
}'

查 KB 找確認過的 trap 解法

curl -X POST :7700/mcp -H "Content-Type: application/json" -d '{
  "jsonrpc":"2.0","id":1,"method":"tools/call",
  "params":{"name":"kb_search","arguments":{
    "query":"Flutter ExpansionTile click",
    "project":"sirin",
    "status":"confirmed"
  }}
}'

派任務給 Multi-agent squad

curl -X POST :7700/mcp -H "Content-Type: application/json" -d '{
  "jsonrpc":"2.0","id":1,"method":"tools/call",
  "params":{"name":"agent_assign_task","arguments":{
    "description":"在 src/foo.rs 加一個 fn bar() 並補單測"
  }}
}'

⚠️ 注意事項

  • 並發 = 1 TEST_RUN_LOCK 同時只跑一個 test。多個 AI client 觸發會排隊（用 queue_status 看 ETA）。
  • Idle close 60s Chrome 60 秒沒 active test 會自動關（SIRIN_BROWSER_IDLE_CLOSE_SECS 可調）。下次 launch 會重開。
  • 無 auth 只 listen 127.0.0.1，本機任何 process 都能連。對外開要自己加 reverse proxy + auth（沒內建 token）。
  • Persistent profile Chrome 用 <app_data_dir>/chrome-profile，登入狀態跨 AI session 共享。
  • KB write 自動 dedup 成功的 test 會自動寫 sirin-pass-{test_id} 到 KB，多 AI 跑同 test 會自動 version up，不會 spam。
  • Replay 優先 有 saved script 的 test 自動走 deterministic replay（0 LLM 成本，5-30s）。沒 script 才走 LLM ReAct（30-300s + token cost）。

🔧 常見問題

Q：MCP call 回 connection refused

Sirin daemon 沒在跑。啟動：

# Windows
./target/release/sirin.exe --headless

# 確認
curl http://127.0.0.1:7700/api/snapshot

Q：test 卡住不動

用 live_trace run_id=... 看執行到第幾步，kill_run run_id=... 強制終止。auto-kill watchdog 90s 也會自動清。

Q：Chrome 沒開

正常——idle close 已關。下個 test 觸發會自動重啟。或直接 browser_exec action=goto target=...。

Q：要看 daemon log

tail_app_log lines=50 tool，或直接看 %LOCALAPPDATA%\Sirin\logs\app.log。
